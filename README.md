# Supply Chain Analysis Project 📊

A capstone project analyzing supply chain data to identify optimization opportunities and business insights.

## Dataset Overview

- **24 columns, 100+ rows** of supply chain data
- Covers product details, pricing, manufacturing, shipping, and costs
- Focus on revenue generation and operational efficiency

## Setup & Requirements

```bash
pip install pandas numpy seaborn matplotlib
```

- Place `supply_chain_data.csv` in project directory
- Run the Jupyter notebook to see the analysis

## Analysis Components

### 🐍 Python Analysis

- Data cleaning and exploration
- Statistical analysis and visualization
- Sales, operations, and shipping analysis

### 🗄️ SQL Queries

- Revenue analysis by product type
- Supplier performance evaluation
- Shipping cost optimization

### 📊 Dashboards

- **Excel**: Summary visualizations and KPIs
- **Power BI**: Interactive dashboard with filters

## Key Findings

### Sales Performance

- **Skincare products** dominate with 45% of business
- **Female customers** prefer skincare/cosmetics
- **Regional sales** concentrated in Kolkata and Delhi

### Operational Issues

- **High defect rates** across all product categories (37% for haircare)
- **Lead time variations** between product types
- **Manufacturing costs** highest for skincare products

### Shipping Insights

- **Carrier B**: Higher cost but faster delivery and better revenue
- **Road transportation**: Most efficient across all routes
- **Air shipping**: Most expensive option

## Tools Used

- **Python**: pandas, numpy, seaborn, matplotlib
- **MySQL**: Database queries and analysis
- **Excel**: Dashboard creation
- **Power BI**: Interactive visualizations
